# مدير الموارد البشرية · HR Manager

تطبيق ويب مستقل (React + TypeScript + Vite + Tailwind) لإدارة الموظفين، مبني على وحدة HR
المأخوذة من مشروع "المهندس المدني" بعد فصلها عن بقية الوحدات الهندسية.

## المزايا
- بطاقات موظفين كاملة (بيانات، عنوان، جهة اتصال طوارئ، حساب بنكي)
- بطاقة هوية عمل قابلة للطباعة (Work ID Card)
- تصاريح عمل (Work Permits) وشهادات سلامة (Safety Certificates)
- الحضور والانصراف
- حاسبة الراتب والأوفر تايم + حاسبة مكافأة نهاية الخدمة
- الإجازات السنوية ومستحقاتها
- تقييمات الأداء
- تقارير شاملة
- إعدادات: اللغة (عربي/إنجليزي)، العملة (10 عملات)، شكل العرض (Android/iOS/بدون إطار)

## التشغيل محليًا

**المتطلبات:** Node.js 18+

```bash
npm install
npm run dev
```

ثم افتح المتصفح على الرابط اللي يطلع بالتيرمنال (افتراضيًا http://localhost:3000).

## البناء للإنتاج

```bash
npm run build
npm run preview
```
